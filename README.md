# Prática Guiada

Web app instalável (PWA) com rotinas guiadas de música e musculação.

## Arquivos

- `index.html`: o app inteiro (telas, estilos, dados e lógica).
- `manifest.webmanifest`: nome, ícone e cores usados quando o app é instalado.
- `sw.js`: faz o app abrir sem internet depois da primeira visita.
- `icon-192.png`, `icon-512.png`: ícone do app.

## Instalar no Android

1. Abra o endereço do GitHub Pages no Chrome.
2. Menu (três pontos) → "Adicionar à tela inicial" ou "Instalar app".
